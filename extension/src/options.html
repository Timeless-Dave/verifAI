VerifAI server

The extension only talks to this address. The default, https://useverifai.vercel.app, needs no setup: it checks citations and judges claims. To keep everything on your own computer, run VerifAI yourself and enter http://127.0.0.1:8741.

If VerifAI runs on this computer, use http://127.0.0.1:8741 to have claims judged too. For another server, paste its https address; the browser asks once for permission to reach it.
