Privacy

This page covers the VerifAI website and the VerifAI browser extension. Last updated 13 November 2026.

What is sent

  • The text you paste, or that you ask the extension to check, is sent to the VerifAI server you use. The default server is https://useverifai.vercel.app. You can point the extension at a VerifAI server on your own computer instead.
  • To check that text, the server sends short pieces of it, such as DOIs, titles, links, and search terms, to public sources: Crossref, OpenAlex, DataCite, doi.org, PubMed, Europe PMC, Open Library, Wikipedia, Wikidata, GDELT, the Wayback Machine, and, when configured, Google Fact Check.
  • To judge whether a source supports a claim, the public site sends the claim and short passages from the sources to an open-weights AI model run by Cloudflare Workers AI. Cloudflare states that it does not use this data to train models. VerifAI running on your own computer judges claims locally and sends nothing to an AI service.
  • Your IP address reaches the server, as it does with any website. It is used only to limit how many checks one address can run.

What is kept

  • VerifAI does not store the text you check, does not build profiles, and sets no tracking cookies. There are no ads and no analytics.
  • The hosting provider keeps short-lived request logs, as every web host does.
  • The extension stores one setting in your browser: the server address you chose. It reads a page only when you ask it to check that page.

What is never done

  • Your text is not sold, shared for advertising, or used to train models.
  • No AI model's memory decides a verdict. The model only reads sources retrieved for that check, and a verdict still needs two independent sources.
